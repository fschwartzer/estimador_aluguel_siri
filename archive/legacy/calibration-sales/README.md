# Artefatos de calibração

Parâmetros, tabelas e relatórios que documentam calibrações de versões
anteriores. Eles não são lidos em tempo de execução pela LITE 1.17.0, mas
foram mantidos como evidência metodológica e para futuras comparações.

Os perfis efetivamente usados pelo aplicativo permanecem declarados no núcleo
ativo, `estimador_knn_core_v6120.py`.
